# 배선 (ESP32 없음: MAX31865·OLED를 Pi에 직결)

> ⚠ Pi 쪽 핀 번호는 Raspberry Pi 공식 핀 배치(40핀 헤더) 기준. **MAX31865 보드 쪽 단자/점퍼는 보드마다 표기가 달라 아직 확인 전** — 보드 앞·뒷면 사진(실크 인쇄)으로 확인한 뒤 아래 "미확인" 항목을 확정한다.

## Pi ↔ MAX31865 (SPI0, CE0)
| MAX31865 핀 | Pi 핀(물리 번호) | Pi 신호 |
|---|---|---|
| VIN | 17 | 3.3V |
| GND | 20 | GND |
| SDI (MOSI) | 19 | GPIO10 / SPI0 MOSI |
| SDO (MISO) | 21 | GPIO9 / SPI0 MISO |
| CLK (SCK) | 23 | GPIO11 / SPI0 SCLK |
| CS | 24 | GPIO8 / SPI0 CE0 |

- OLED(SSD1306, I2C)는 1(3.3V)·3(SDA)·5(SCL)·6(GND)번을 쓰므로 겹치지 않는다.
- SPI는 기본 꺼져 있음 → `sudo raspi-config` → Interface Options → SPI → Enable (sudo 필요, 사용자가 실행). 확인: `ls /dev/spidev0.0`

## MAX31865 ↔ PT100 (3선식: 파랑 2가닥 = 소자 한쪽, 빨강 1가닥 = 반대쪽)
- **미확인:** 3선식 점퍼 설정(보드 뒷면 "2/3 Wire", "24 / 3" 같은 납땜 패드)과 어느 단자(F+, RTD+, RTD-, F-)에 어느 색을 연결하는지.
- 보드 사진 확인 후 확정. 확정 전에는 결선하지 말 것 (잘못하면 온도가 크게 틀리게 나옴).
- RREF: 보드 위 기준 저항 표기 확인 (PT100용은 보통 430Ω = "4300" 또는 "431"). 다르면 `sensor/config.json`의 `rref` 수정.

## 확인 순서 (결선 후)
1. 테스터: 파랑–파랑 ≈ 0Ω, 파랑–빨강 ≈ 108~110Ω (실온)
2. `sensor/` 설정 후 리더 1회 실행 → 실온에서 20~25℃ 근처가 나오는지
3. 얼음물에 담그면 0℃ 근처 (±0.5℃)
